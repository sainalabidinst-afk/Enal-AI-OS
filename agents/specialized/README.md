# Specialized Agents (Phase 2+)

This directory will contain specialized agents for:
- Coding (Python, React, Vue, Flutter, Laravel, Node, FastAPI, Go, Rust, Java)
- Database (MySQL, PostgreSQL, MongoDB, Redis, Supabase)
- DevOps (Docker, Linux, Nginx, CI/CD, Git, GitHub, Cloud)
- UI/UX (Designer, UX, Tailwind, Figma, Animation)
- AI/ML (Prompt Engineer, ML Engineer, RAG, Embedding, LangGraph, MCP, CrewAI, AutoGen)
- Business (Marketing, Finance, Accounting, Legal, HR)
- Networking (Cisco, Mikrotik, Fortigate, Linux Network, VPN, BGP, Firewall, Fiber)
- Trading (Market, Indicator, Risk, Portfolio, News, Sentiment, Execution)

Each agent will have its own module with:
- Role definition
- System prompt
- Tool bindings
- Specialized knowledge base
