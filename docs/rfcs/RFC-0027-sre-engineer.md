## Motivasi

As systems grow in complexity, Site Reliability Engineering becomes critical for:

1. **Observability Setup** — Prometheus, Grafana, OpenTelemetry, distributed tracing
2. **SLO Design** — error budgets, alerting policies, burn rate notifications
3. **Incident Response** — runbooks, escalation, post-mortems
4. **Capacity Planning** — forecasting, autoscaling, resource optimization

Capability Pack SRE Engineer provides the reliability layer between development and operations.

---

## Tujuan

1. **Observability Setup** — metrics, logs, traces with Prometheus/Grafana/OpenTelemetry
2. **SLO Design** — service-level objectives with error budget policies
3. **Incident Response** — runbooks, escalation paths, post-mortem templates
4. **Capacity Planning** — resource forecasting, autoscaling configuration
