# Research Real Cases

Real research questions and source analysis encountered while using ECP.

## Case Template

Create a folder for each case:

```
<case_name>/
├── input/
│   ├── question.md
│   └── sources/
├── output/
│   ├── literature_review.md
│   ├── synthesis.md
│   └── citations.md
└── evaluation.md
```

## Example Cases

- `ai_security_survey/` — Survey of AI security papers
- `market_efficiency/` — Market efficiency hypothesis research
- `protocol_comparison/` — Network protocol comparison study
